# Repository instructions

## README changes require explicit user approval

`README.md` is approved public-facing copy. Do not change, extend, reformat or regenerate it without the repository owner's explicit approval for the intended change. General requests to add countries, languages, features, fixes or releases do not authorize README edits.

An explicit approval already given for the current task is sufficient; do not ask for the same approval again. Once that approved change is complete, future README changes require new explicit approval.

Keep implementation details, architecture notes, JSON examples and developer instructions in the relevant files under `docs/`, unless the user explicitly approves their inclusion in the README.
